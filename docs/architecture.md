# 系统架构

## 概述

wll_OS 是一个基于 Rust 语言的操作系统内核，采用微内核设计风格，支持 RISC-V64 和 LoongArch64 两种架构。

## 架构分层

```
┌─────────────────────────────────────────┐
│           用户空间 (User Space)          │
│         ELF 应用程序 / 测试脚本           │
├─────────────────────────────────────────┤
│              系统调用接口                 │
│      (syscall/mod.rs, syscall/*.rs)     │
├─────────────────────────────────────────┤
│           内核核心 (Kernel Core)          │
│  ┌─────────┐ ┌─────────┐ ┌──────────┐  │
│  │ 进程管理 │ │ 内存管理 │ │ 文件系统  │  │
│  │  task/  │ │   mm/   │ │    fs/    │  │
│  └─────────┘ └─────────┘ └──────────┘  │
│  ┌─────────┐ ┌─────────┐ ┌──────────┐  │
│  │ 中断处理 │ │ 控制台  │ │ 工具库    │  │
│  │  trap/  │ │ console │ │  utils/   │  │
│  └─────────┘ └─────────┘ └──────────┘  │
├─────────────────────────────────────────┤
│         硬件抽象层 (HAL)                  │
│         polyhal / polyhal-trap          │
├─────────────────────────────────────────┤
│           硬件 (Hardware)                 │
│     RISC-V / LoongArch / QEMU virt      │
└─────────────────────────────────────────┘
```

## 核心模块

### 1. 内存管理 (mm/)

- **frame_allocator.rs**: 物理页帧分配器，使用伙伴系统
- **page_table.rs**: 页表管理，封装架构相关的页表操作
- **memory_set.rs**: 地址空间管理，管理进程的虚拟内存
- **map_area.rs**: 虚拟内存区域定义
- **elf_loader.rs**: ELF 文件解析和加载

### 2. 进程管理 (task/)

- **task.rs**: 任务控制块 (TaskControlBlock) 实现
- **manager.rs**: 就绪队列管理
- **processor.rs**: CPU 状态管理
- **context.rs**: 上下文切换（汇编代码）
- **pid.rs**: PID 分配器

### 3. 文件系统 (fs/)

- **mod.rs**: 内存文件系统 (MemFS) 实现
- **fd.rs**: 文件描述符管理

### 4. 系统调用 (syscall/)

- **mod.rs**: 系统调用号定义和分发
- **fs.rs**: 文件相关系统调用
- **process.rs**: 进程相关系统调用
- **mm.rs**: 内存相关系统调用（待实现）
- **signal.rs**: 信号相关系统调用（待实现）
- **other.rs**: 其他系统调用（待实现）

### 5. 中断处理 (trap/)

- **mod.rs**: 中断处理入口和系统调用处理
- **interrupts.rs**: 中断处理辅助函数

## 启动流程

1. **Boot**: polyhal-boot 完成早期硬件初始化
2. **Entry**: `rust_main()` 是 Rust 入口点
3. **Init**: 初始化各个子系统
   - `mm::init()`: 内存管理
   - `trap::init()`: 中断处理
   - `fs::init()`: 文件系统
   - `add_initproc()`: 加载 init 进程
4. **Schedule**: `run_tasks()` 启动调度器

## 跨架构支持

### 架构配置

- **RISC-V**: `config/rv.rs`
- **LoongArch**: `config/la.rs`

### 关键差异

| 特性 | RISC-V | LoongArch |
|------|--------|-----------|
| 内核基址 | 0x8020_0000 | 0x9000_0000_9000_0000 |
| 虚拟地址起始 | 0xffff_ffff_0000_0000 | 0x9000_0000_0000_0000 |
| 陷阱处理 | ecall + stvec | syscall1 + eentry |
| 页表级数 | 3级 (SV39) | 3级或4级 |

polyhal 库封装了这些差异，提供统一的接口。

## 内存布局

### 内核空间（高地址）

```
┌─────────────────────────┐ ← VIRT_ADDR_START (0xffff_ffff_0000_0000)
│      内核代码和数据       │
├─────────────────────────┤
│      内核堆 (Heap)       │
├─────────────────────────┤
│      内核栈 (每个CPU)     │
├─────────────────────────┤
│      设备内存映射         │
└─────────────────────────┘
```

### 用户空间（低地址）

```
├─────────────────────────┤ ← 0x8000_0000 (USER_STACK_TOP)
│      用户栈 (向下增长)    │
├─────────────────────────┤
│      堆 (向上增长)         │
├─────────────────────────┤
│      BSS 段             │
├─────────────────────────┤
│      数据段              │
├─────────────────────────┤
│      代码段              │
├─────────────────────────┤
│      ELF 头              │
└─────────────────────────┘ ← 0x1000 (USER_START_ADDR)
```
