# Syscall Matrix

Status legend:

- `real`: implemented with kernel state or real backing objects.
- `partial`: useful subset or compatible behavior, but not full Linux semantics.
- `stub-ok`: fixed success or simplified value that is enough for current suites.
- `stub-risk`: currently unblocks simple cases but likely fails broader suites.
- `missing`: not dispatched or returns `ENOSYS`.

## Current Foundation

| Area | Status | Main files | Notes |
| --- | --- | --- | --- |
| Process lifecycle: `clone`, `execve`, `exit`, `exit_group`, `wait4`, `yield` | `partial` | `os/src/syscall/process.rs`, `os/src/task/mod.rs`, `os/src/task/wait_queue.rs` | `wait4` reaps process-zombie children across the caller's thread group; `exit_group` terminates the whole TGID; raw `exit` terminates the calling thread and marks the process zombie only when the last user thread exits. `execve` closes `FD_CLOEXEC` descriptors and kills peer threads before replacing the shared address space. Process groups, job control, ptrace-style wait options, robust futex, and complete pthread semantics remain incomplete. |
| Memory: `brk`, `mmap`, `munmap`, `mprotect` | `partial` | `os/src/syscall/mm.rs`, `os/src/mm/*` | `brk` now grows and shrinks page-backed heap ranges while preserving the old break on invalid requests. Anonymous `mmap` plus partial-range `munmap`/`mprotect` are real for libc-style private mappings. File-backed mappings remain partial: writable `MAP_SHARED` writes the unmapped range back on `munmap`, but dirty tracking, `msync`, and full shared-page coherence are still missing. |
| Filesystem path ops: `openat`, `mkdirat`, `unlink`, `unlinkat`, `rmdir`, `rename`, `renameat`, `renameat2`, `link`, `linkat`, `symlink`, `symlinkat`, `readlinkat`, `truncate`, `statx`, `newfstatat`, `access`, `faccessat`, `faccessat2` | `partial` | `os/src/fs/vfs.rs`, `os/src/syscall/fs.rs`, `os/src/syscall/mod.rs`, `os/src/fs/ext4_vol.rs` | Path metadata/open/readlink/truncate and path mutation enter VFS and share missing-path/type errno handling for common `ENOENT`/`ENOTDIR`/`EISDIR`/`EEXIST`/`ENOTEMPTY`/`EXDEV`/`ELOOP` cases. Old asm-generic path syscalls are compatibility wrappers over the same VFS operations. Real ext4 rename/link/symlink/unlink/rmdir are implemented for simple same-filesystem cases; MemFS overlay removals use VFS whiteouts. Cross-backend hard links/renames, full directory-replacement semantics, full permission/credential checks, `O_PATH`, and full symlink traversal remain partial. |
| FS metadata/sync: `statfs`, `fstatfs`, `sync`, `fsync`, `fdatasync` | `partial` to `stub-risk` | `os/src/fs/vfs.rs`, `os/src/fs/ext4_vol.rs`, `os/src/syscall/fs.rs`, `os/src/syscall/mod.rs` | `statfs/fstatfs` validate path/fd and return ext4 superblock-derived block/inode counts when ext4 is mounted, with a MemFS-derived fallback when no ext4 root exists. `stat`/`statx`/`fstat` report post-write and post-truncate size plus block counts from real ext4 inode metadata with a 512-byte-block fallback. `sync`/`fsync`/`fdatasync` now enter VFS sync validation and `fsync`/`fdatasync` reject pipes; current MemFS/ext4 file writes are already write-through, so sync is compatibility-correct for in-kernel visibility but still `stub-risk` for real persistence/journal/cache flush semantics. |
| FD I/O: `read`, `write`, `readv`, `writev`, `pread64`, `lseek`, `getdents64`, `sendfile`, `dup`, `dup3`, `fcntl` | `partial` | `os/src/fs/fd.rs`, `os/src/syscall/fs.rs` | Regular files, dirs, console, pipes, and socket descriptors are covered as fd-table objects. MemFS and ext4 regular fds track read/write access, `O_APPEND`, and fixed-offset `pread64` without moving the fd offset. `write` appends at current EOF when `O_APPEND` is set; `lseek` allows seeking past EOF without changing file size, rejects negative/overflow positions, and returns `ESPIPE` for pipes/sockets. Writes and truncate/ftruncate update file size and metadata-backed block counts; large offset/count overflow returns `EFBIG`. Pipes now use bounded in-kernel buffering with blocking read/write through wait queues and `O_NONBLOCK` returning `EAGAIN` when the operation would sleep. Socket `read`/`recvfrom` and `write`/`sendto` share fd state: in-kernel loopback streams use peer byte queues, datagrams use bound local receive queues, unconnected streams return `ENOTCONN`, and no-data receive paths return `EAGAIN` until full socket blocking is implemented. Per-fd `FD_CLOEXEC` is tracked for `openat(O_CLOEXEC)`, `socket(SOCK_CLOEXEC)`, `pipe2(O_CLOEXEC)`, `dup3(O_CLOEXEC)`, `fcntl(F_GETFD/F_SETFD/F_DUPFD_CLOEXEC)`, and `execve` close. `fcntl(F_SETFL)` mutates pipe/socket `O_NONBLOCK` and regular-file `O_APPEND`; descriptor-shared offsets/status flags, full socket blocking waits, and `pwrite*`/`preadv*` remain `partial`/`missing`. |
| Pipes and polling: `pipe2`, `ppoll`, `pselect6` | `partial` | `os/src/fs/fd.rs`, `os/src/syscall/fs.rs`, `os/src/task/wait_queue.rs` | Regular file read/write readiness is immediate, including EOF. Pipe read readiness is based on buffered bytes or writer shutdown; pipe write readiness is based on reader presence and remaining pipe capacity. `POLLHUP` and write-side `POLLERR` are reported from pipe endpoint state. `ppoll`/`pselect6` timeouts use validated signed `timespec` values and wait on IO queues without busy looping. Socket fds participate in poll/select readiness from pending accepts, stream receive bytes, datagram receive packets, shutdown, and error state; external-network readiness and fully blocking socket waits are still missing. |
| Signals: `rt_sigaction`, `rt_sigprocmask`, `rt_sigtimedwait`, `rt_sigreturn`, `kill`, `tkill`, `tgkill` | `partial` | `os/src/syscall/signal.rs`, `os/src/task/mod.rs`, `os/src/task/wait_queue.rs` | Linux-style `rt_sigaction` handler/flags/restorer/mask layout is supported; `SA_RESTORER`, `SA_NODEFER`, `SA_RESETHAND`, per-task blocked masks, pending bits, `rt_sigreturn` trap-frame restore, and EINTR wakeups for wait-queue sleeps are real. `rt_sigtimedwait` consumes matching pending signals, reports minimal siginfo, and uses the timer wait queue for timeout-to-`EAGAIN`. `SA_SIGINFO` gets a minimal siginfo pointer, but the third argument is not a full Linux `ucontext_t`. `SA_RESTART`, `SA_ONSTACK`, `SA_NOCLDSTOP`, `SA_NOCLDWAIT`, `SA_INTERRUPT`, and `SA_EXPOSE_TAGBITS` are accepted as compatibility flags with partial/no effect. `sigsuspend`, process groups, alt signal stacks, shared process-pending queues, syscall restart, realtime signal queuing, and full default stop/continue/core actions remain incomplete. |
| Futex: `futex WAIT/WAKE/WAIT_BITSET/WAKE_BITSET` | `partial` | `os/src/syscall/other.rs`, `os/src/task/wait_queue.rs` | `WAIT` validates aligned user addresses, compares the user word before sleeping, rechecks before blocking, supports relative timeout, and returns `EAGAIN`/`ETIMEDOUT`/`EINTR` on the real wait path. `WAKE` validates the futex address and wakes address/key-matched waiters. `WAIT_BITSET`/`WAKE_BITSET` share the same wait path with bitset filtering and absolute timeout handling. Unsupported futex ops return `ENOSYS` instead of fake success. PI, requeue, robust list cleanup, shared-process details, and full pthread cancellation semantics remain `missing`/`partial`. |
| Time/system info: `nanosleep`, `clock_gettime`, `gettimeofday`, `times`, `uname`, `sysinfo`, `getrandom` | `partial` | `os/src/syscall/other.rs`, `os/src/timer.rs` | Enough for libc startup and basic utilities. Accuracy and clock IDs are simplified. |
| Scheduler/rlimit/identity stubs | `stub-ok` to `stub-risk` | `os/src/syscall/other.rs`, `os/src/syscall/mod.rs` | UID/GID are fixed zero. Scheduler calls mostly return success. |
| Networking: socket family | `partial` | `os/src/syscall/net.rs`, `os/src/fs/fd.rs`, `os/src/syscall/fs.rs`, `os/src/syscall/mod.rs` | `socket` creates real fd-table socket descriptors with `SOCK_NONBLOCK`/`SOCK_CLOEXEC`; `bind` validates local sockaddrs, assigns ephemeral ports for port 0, and records bound sockets; `listen` records stream listener state; `connect` to a bound in-kernel listener queues a real accepted socket; `accept/accept4` returns pending stream sockets and reports `EAGAIN` for nonblocking no-pending-connection. Datagram `sendto`/`recvfrom` deliver payloads through bound local receive queues, and stream `read`/`write`/`sendto`/`recvfrom` use peer byte queues after loopback connect. `getsockname/getpeername`, `shutdown`, `getsockopt/setsockopt` for common `SOL_SOCKET` options including `SO_PROTOCOL` plus `TCP_NODELAY`, and socket `ioctl(FIONBIO/FIONREAD)` have compatibility behavior. There is still no virtio-net/external network path, no real TCP congestion/window/close protocol, no UDP routing beyond local bound sockets, no `socketpair`, and limited socket option/ioctl coverage; unsupported protocols/options return `EPROTONOSUPPORT`, `ENOPROTOOPT`, `ECONNREFUSED`, or `EOPNOTSUPP` rather than success. |

## Process Lifecycle Details

| Syscall / area | Status | Current semantics | Remaining risk |
| --- | --- | --- | --- |
| `wait4` child selection | `partial` | `pid == -1` and `pid == 0` wait for any child process in the caller's thread group; positive `pid` matches child TGID. A live child with `WNOHANG` returns `0`; no matching child returns `ECHILD`. Threads created with `CLONE_THREAD` are not waitable children. | `pid < -1` process-group waits are `missing`; stopped/continued states and Linux wait option filtering are not modeled. |
| `exit` / `exit_group` | `partial` | Raw `exit` makes only the current task zombie, clears `clear_child_tid`, wakes futex waiters, and marks the process zombie when all user threads are gone. `exit_group` applies that termination to every user thread in the TGID and wakes child waiters once. | Signal default actions and robust-list cleanup are incomplete. |
| `clone` flags | `partial` | Accepts `CLONE_VM`, `CLONE_FS`, `CLONE_FILES`, `CLONE_SIGHAND`, `CLONE_THREAD`, `CLONE_SYSVSEM`, `CLONE_SETTLS`, `CLONE_PARENT_SETTID`, `CLONE_CHILD_SETTID`, and `CLONE_CHILD_CLEARTID`. Enforces `CLONE_SIGHAND -> CLONE_VM` and `CLONE_THREAD -> CLONE_SIGHAND`. `getpid()` returns TGID; `gettid()` returns task PID; `getppid()` returns parent TGID. | Unsupported clone bits return `EINVAL`; `CLONE_SYSVSEM` is accepted as compatibility state only. `CLONE_PARENT`, namespaces, signal-group details, TLS arch edge cases, and full pthread/futex semantics remain `missing`/`stub-risk`. |
| `execve` lifecycle | `partial` | Replaces the current address space, resets signal handlers, updates `exec_path`, terminates peer threads in the TGID, and closes descriptors marked `FD_CLOEXEC`. | Linux's full exec credential, dumpability, robust futex, and process-group/session side effects are not modeled. |

## Memory Details

| Syscall / area | Status | Current semantics | Remaining risk |
| --- | --- | --- | --- |
| `brk` heap growth/shrink | `real` for the tracked heap range | `brk(0)` returns the current break. Valid growth maps new anonymous heap pages, valid shrink unmaps pages above the new rounded break, and sub-page break movement only updates the logical break. Invalid below-heap, overflow, stack-boundary, overlap, or allocation-failure requests preserve the old break, matching raw Linux `brk` behavior used by libc allocators. | No overcommit policy, guard gap, or per-VMA heap tag; a user can still deliberately replace heap pages with `MAP_FIXED`, as on Linux. |
| Anonymous `mmap` | `real` for private/shared anonymous pages used by libc | Requires one of `MAP_PRIVATE`, `MAP_SHARED`, or `MAP_SHARED_VALIDATE`, validates `prot`, length, fixed-address alignment, user range, and common Linux compatibility flags. Non-fixed hints are page aligned and fall back to a free region. `MAP_FIXED_NOREPLACE` returns `EEXIST` on overlap; fixed address 0 is rejected with `EPERM`. | No lazy fault, overcommit accounting, `MAP_GROWSDOWN`, huge pages, locked memory, or NUMA/accounting semantics. Compatibility flags such as `MAP_STACK`, `MAP_POPULATE`, and `MAP_NORESERVE` are accepted with no special effect. |
| `munmap` | `real` for page-aligned partial VMA removal | Splits VMAs at page boundaries, unmaps the requested range even when it cuts through an area, and coalesces surviving adjacent areas. Writable shared file-backed ranges are written back before removal. | No dirty-page tracking; writeback is range-wide and eager for shared file-backed mappings. |
| `mprotect` | `partial` | Validates alignment/length/prot, requires the full range to be mapped, splits VMAs, and rewrites page-table permissions. `PROT_WRITE` also grants read permission to avoid invalid RISC-V W-without-R PTEs. | No architecture-specific execute/cache synchronization beyond remapping, and no Linux personality/read-implies-exec behavior. |
| File-backed `mmap` | `partial` | Readable regular file descriptors can be copied into private/shared framed VMAs; writable `MAP_SHARED|PROT_WRITE` requires a writable descriptor and writes back on `munmap` or fixed replacement. | Not a complete page-cache mapping: no lazy population, shared physical page coherence, partial dirty tracking, `msync`, truncate invalidation, or DAX/`MAP_SYNC`; unsupported validated flags report `EOPNOTSUPP`/`EINVAL` instead of pretending success. |

## Signal Details

| Syscall / area | Status | Current semantics | Remaining risk |
| --- | --- | --- | --- |
| `rt_sigaction` ABI and flags | `partial` | Uses the common Linux kernel layout `{ handler, flags, restorer, mask }`. Unsupported/probing bits are cleared from stored actions; `SIGKILL` and `SIGSTOP` cannot be caught or ignored. `SA_RESTORER`, `SA_NODEFER`, and `SA_RESETHAND` affect delivery. `SA_SIGINFO` provides a minimal 128-byte siginfo with signo/code/sender pid. | No full `ucontext_t`, alternate signal stack, or syscall restart. `SA_RESTART`, `SA_ONSTACK`, `SA_NOCLDSTOP`, `SA_NOCLDWAIT`, `SA_INTERRUPT`, and `SA_EXPOSE_TAGBITS` are compatibility-accepted but not fully modeled. |
| `rt_sigprocmask` / pending relation | `partial` | Each task has a real blocked mask and pending bitset; `SIGKILL`/`SIGSTOP` are removed from user masks. Unblocking exposes pending signals, and deliverable pending signals interrupt wait-queue sleeps with `EINTR`. | Process-wide shared pending queues and realtime queued-signal multiplicity are missing. |
| `rt_sigreturn` | `partial` | Restores the saved arch trap frame and previous blocked mask from the user signal frame, then returns to the interrupted PC without advancing the syscall PC. | The frame is kernel-private, not a complete Linux `ucontext_t` ABI. Corrupt frames fail with `EINVAL`. |
| `kill` / `tkill` / `tgkill` targets | `partial` | Positive `kill(pid, sig)` targets the TGID and prefers a live thread that is not blocking the signal; `tkill` targets a TID; `tgkill` verifies TID membership in TGID. Signal 0 validates targets without delivery. `kill(-1, sig)` targets all user tasks. | Process groups (`pid == 0` as caller process group and `pid < -1`) are not real; the BusyBox-compatible "seen TGID" success path remains for exited positive TGIDs. |
| `sigsuspend` / `sigtimedwait` | `missing` / `partial` | `sigsuspend` is still not dispatched. `rt_sigtimedwait` reads the user signal set, consumes matching pending signals, writes minimal siginfo, waits with a timeout, and returns `EAGAIN` on timeout. | Shared process-pending queues, realtime queued-signal multiplicity, restart behavior, and full `siginfo_t`/`ucontext_t` details remain incomplete. |

## High-Priority Gaps

1. Harden FD/VFS contract before more suites: `os/src/fs/vfs.rs`, `os/src/fs/fd.rs`, `os/src/syscall/fs.rs`.
   Broaden descriptor-shared status flags beyond the current pipe `O_NONBLOCK` and regular `O_APPEND` subset, then finish full rename/link/symlink semantics and clearer metadata/open tests around MemFS overlay plus ext4.

2. Make blocking semantics observable and less foreground-specific: `os/src/task/wait_queue.rs`, `os/src/task/mod.rs`, `os/src/syscall/process.rs`, `os/src/syscall/other.rs`.
   Extend `BlockReason` into debug logs and replace remaining direct blocking entry points as new waits appear.

3. Finish pthread/libc basics: `os/src/syscall/process.rs`, `os/src/syscall/other.rs`, `os/src/syscall/signal.rs`.
   Prioritize pthread cancellation/exit status, robust futex cleanup, `clone` thread semantics, shared futex keys, `set_robust_list`, and `rt_sigsuspend`.

4. File workload support for `iozone` and UnixBench: `os/src/fs/ext4_vol.rs`, `os/src/mm/memory_set.rs`, `os/src/syscall/mm.rs`.
   Add `pwrite64`/`preadv`/`pwritev`, dirty tracking/`msync` for shared mappings, descriptor-shared file offsets, sparse-hole accounting, larger buffered file paths, and less stubby persistence for `fsync`/`fdatasync`.

5. Network suites last: extend the new `os/src/syscall/net.rs` socket fd layer from local in-kernel loopback queues to a real TCP/IP or minimal virtio-net-backed packet path.
   The fd lifecycle, option compatibility, nonblocking errno, local connect/accept, local payload queues, and poll/select hooks exist; the next step is a real network stack boundary with protocol semantics.

## Suggested Enable Order

1. Keep `basic`, `busybox`, and `lua` as the default harness groups.
2. Run `libc-test` only as an explicit staged collection phase until the harness can execute the official `libctest_testcode.sh` bodies directly or the wrapper boundary is accepted as a documented compatibility mode.
3. Keep the already-passing `basic`/`busybox` groups under dual-architecture regression while collecting libc-test evidence from real serial logs.
4. Grow `libc-test` by real failing categories, starting with startup/file/process/memory, then pthread/signal.
5. Enable `iozone` after ext4 write/truncate/fsync and mmap behavior are stable.
6. Enable `UnixBench` after scheduler, pipe, wait, and timing behavior are less synthetic.
7. Enable `LTP` only after the matrix is split by LTP subsystem.
8. Enable `iperf/netperf` only after the socket layer has a real network data path and protocol semantics, not just local fd/loopback queue support.
