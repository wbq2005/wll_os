# Syscall Matrix

Status legend:

- `real`: implemented with kernel state or real backing objects.
- `partial`: useful subset or compatible behavior, but not full Linux semantics.
- `stub-ok`: fixed success or simplified value that is enough for current suites.
- `stub-risk`: currently unblocks simple cases but likely fails broader suites.
- `missing`: not dispatched or returns `ENOSYS`.

## Current Foundation

| Area | Status | Main files | Notes |
| --- | --- | --- | --- |
| Process lifecycle: `clone`, `execve`, `exit`, `exit_group`, `wait4`, `yield` | `partial` | `os/src/syscall/process.rs`, `os/src/task/mod.rs`, `os/src/task/wait_queue.rs` | `wait4` reaps process-zombie children across the caller's thread group; `exit_group` terminates the whole TGID; raw `exit` terminates the calling thread and marks the process zombie only when the last user thread exits. Process exit now queues `SIGCHLD` to the user parent so blocked `rt_sigtimedwait(SIGCHLD)` users can observe child completion before `wait4`. `sched_yield` gives another ready task one real scheduling opportunity in foreground mode instead of returning a no-op success. `execve` closes `FD_CLOEXEC` descriptors, kills peer threads before replacing the shared address space, and resolves `/proc/self/exe`/`/proc/thread-self/exe` to the current task's executable for BusyBox/glibc self-reexec paths. Thread exit clears `clear_child_tid`, wakes the matching futex key, performs partial robust-list owner-death cleanup for non-PI robust mutexes, and purges the exiting task from ready, futex, timer, IO, child-exit, and signal wait structures. Process groups, job control, ptrace-style wait options, and complete pthread semantics remain incomplete. |
| Memory: `brk`, `mmap`, `munmap`, `mprotect`, SysV `shm*` | `partial` | `os/src/syscall/mm.rs`, `os/src/mm/*` | `brk` now grows and shrinks page-backed heap ranges while preserving the old break on invalid requests. Anonymous `mmap` plus partial-range `munmap`/`mprotect` are real for libc-style private mappings, including reserved `PROT_NONE` VMAs that are populated when `mprotect` later grants leaf permissions. Basic SysV shared memory now dispatches `shmget`/`shmat`/`shmdt`/`shmctl(IPC_STAT, IPC_RMID)` with real shared physical frames across fork, task-exit/exec detach accounting, and `IPC_PRIVATE`/keyed segment lookup. File-backed mappings remain partial: writable `MAP_SHARED` writes the unmapped range back on `munmap`, but dirty tracking, `msync`, and full shared-page coherence are still missing. |
| Filesystem path ops: `openat`, `mkdirat`, `unlink`, `unlinkat`, `rmdir`, `rename`, `renameat`, `renameat2`, `link`, `linkat`, `symlink`, `symlinkat`, `readlinkat`, `truncate`, `statx`, `newfstatat`, `access`, `faccessat`, `faccessat2` | `partial` | `os/src/fs/vfs.rs`, `os/src/syscall/fs.rs`, `os/src/syscall/mod.rs`, `os/src/fs/ext4_vol.rs` | Path metadata/open/readlink/truncate and path mutation enter VFS and share missing-path/type errno handling for common `ENOENT`/`ENOTDIR`/`EISDIR`/`EEXIST`/`ENOTEMPTY`/`EXDEV`/`ELOOP` cases. Old asm-generic path syscalls are compatibility wrappers over the same VFS operations. Real ext4 rename/link/symlink/unlink/rmdir are implemented for simple same-filesystem cases; MemFS overlay removals use VFS whiteouts. MemFS now provides writable `/tmp` and `/var/tmp` plus pseudo `/dev/null` and `/dev/zero` for the global, `/glibc`, and `/musl` roots. `/dev/null` and `/dev/zero` report character-device metadata and real null/zero read-write behavior, so libc `stat`, daemon setup checks, and raw sign-extension reads use real pseudo-device semantics. Cross-backend hard links/renames, full directory-replacement semantics, full permission/credential checks, `O_PATH`, and full symlink traversal remain partial. |
| FS metadata/sync: `statfs`, `fstatfs`, `sync`, `fsync`, `fdatasync` | `partial` to `stub-risk` | `os/src/fs/vfs.rs`, `os/src/fs/ext4_vol.rs`, `os/src/syscall/fs.rs`, `os/src/syscall/mod.rs` | `statfs/fstatfs` validate path/fd and return ext4 superblock-derived block/inode counts when ext4 is mounted, with a MemFS-derived fallback when no ext4 root exists. `stat`/`statx`/`fstat` report post-write and post-truncate size plus block counts from real ext4 inode metadata with a 512-byte-block fallback, and now carry `st_rdev` / `statx` rdev major-minor for pseudo character devices such as `/dev/null` (1:3) and `/dev/zero` (1:5). Ext4 regular writes are cached in kernel memory for iozone-sized small-block workloads and flushed through `fsync`, `fdatasync`, `sync`, timestamp updates, and VFS sync paths, while stat/ftruncate observe cached size before flush. Full ext4 journal/device persistence remains `stub-risk`. |
| FD I/O: `read`, `write`, `readv`, `writev`, `pread64`, `pwrite64`, `preadv`, `pwritev`, `lseek`, `getdents64`, `sendfile`, `dup`, `dup3`, `fcntl` | `partial` | `os/src/fs/fd.rs`, `os/src/syscall/fs.rs` | Regular files, dirs, console, pipes, sockets, and pseudo character devices are covered as fd-table objects. MemFS fds keep per-descriptor offsets/flags but refresh file content from the authoritative MemFS object before reads, fixed-offset reads, writes, truncates, and fstat metadata, so forked descriptors and separately opened fds see each other's write-through content. Ext4 regular fds track read/write access, `O_APPEND`, and fixed-offset `pread64`/`pwrite64` without moving the fd offset; vector fixed-offset calls are routed through the same partial fd paths. `/dev/null` reads EOF and discards writes; `/dev/zero` reads zero-filled buffers and discards writes. `write` appends at current EOF when `O_APPEND` is set; `lseek` allows seeking past EOF without changing file size, rejects negative/overflow positions, and returns `ESPIPE` for pipes/sockets. Writes and truncate/ftruncate update file size and metadata-backed block counts; large offset/count overflow returns `EFBIG`. Pipes use bounded in-kernel buffering with blocking read/write through wait queues and `O_NONBLOCK` returning `EAGAIN`; `write` to a pipe with no readers now queues `SIGPIPE` before returning `EPIPE` if the signal is ignored/handled. Socket `read`/`recvfrom` and `write`/`sendto` share fd state: in-kernel loopback streams use peer byte queues, datagrams use bound local receive queues, unconnected streams return `ENOTCONN`, and no-data receive paths return `EAGAIN` until full socket blocking is implemented. Per-fd `FD_CLOEXEC` is tracked for `openat(O_CLOEXEC)`, `socket(SOCK_CLOEXEC)`, `pipe2(O_CLOEXEC)`, `dup3(O_CLOEXEC)`, `fcntl(F_GETFD/F_SETFD/F_DUPFD_CLOEXEC)`, and `execve` close. `fcntl(F_SETFL)` mutates pipe/socket `O_NONBLOCK` and regular-file `O_APPEND`; true shared open-file descriptions for offsets/status flags, full socket blocking waits, sparse-hole accounting, and high-throughput pwrite/pwritev paths remain `partial`/`stub-risk`. |
| Pipes and polling: `pipe2`, `ppoll`, `pselect6` | `partial` | `os/src/fs/fd.rs`, `os/src/syscall/fs.rs`, `os/src/task/wait_queue.rs` | Regular file read/write readiness is immediate, including EOF. Pipe read readiness is based on buffered bytes or writer shutdown; pipe write readiness is based on reader presence and remaining pipe capacity. `POLLHUP` and write-side `POLLERR` are reported from pipe endpoint state. `ppoll`/`pselect6` timeouts use validated signed `timespec` values and wait on IO queues without busy looping. `pselect6` now preserves the caller's original interest fdsets across the kernel-internal wait loop and writes result fdsets only when returning ready/timeout to user space. Socket fds participate in poll/select readiness from pending accepts, stream receive bytes, datagram receive packets, shutdown, and error state; external-network readiness and fully blocking socket waits are still missing. |
| Signals: `rt_sigaction`, `rt_sigprocmask`, `rt_sigsuspend`, `rt_sigtimedwait`, `rt_sigreturn`, `kill`, `tkill`, `tgkill` | `partial` | `os/src/syscall/signal.rs`, `os/src/task/mod.rs`, `os/src/task/wait_queue.rs` | Linux-style `rt_sigaction` handler/flags/restorer/mask layout is supported; `SA_RESTORER`, `SA_NODEFER`, `SA_RESETHAND`, per-task blocked masks, pending bits, `rt_sigreturn` trap-frame restore, and EINTR wakeups for wait-queue sleeps are real. `rt_sigprocmask` strips `SIGKILL`, `SIGSTOP`, and glibc/NPTL internal cancellation/setxid signals 32/33 from user-blockable masks. `rt_sigsuspend` installs the temporary mask, sleeps on the signal wait queue, returns `EINTR` when a signal is delivered, and restores the pre-suspend mask through the signal frame. `rt_sigtimedwait` consumes matching pending signals, including child-exit `SIGCHLD`, reports minimal siginfo, and uses the timer wait queue for timeout-to-`EAGAIN`. Pipe write-side `EPIPE` now raises `SIGPIPE` for the current task, so default-disposition writers terminate instead of spinning on broken pipes. `SA_SIGINFO` gets a minimal siginfo pointer, but the third argument is not a full Linux `ucontext_t`. `SA_RESTART`, `SA_ONSTACK`, `SA_NOCLDSTOP`, `SA_NOCLDWAIT`, `SA_INTERRUPT`, and `SA_EXPOSE_TAGBITS` are accepted as compatibility flags with partial/no effect. Process groups, alt signal stacks, shared process-pending queues, syscall restart, realtime signal queuing, and full default stop/continue/core actions remain incomplete. |
| Futex: `futex WAIT/WAKE/WAIT_BITSET/WAKE_BITSET`, `set_robust_list`, `get_robust_list` | `partial` | `os/src/syscall/other.rs`, `os/src/task/wait_queue.rs`, `os/src/task/mod.rs` | `WAIT` validates aligned user addresses, compares the user word before sleeping, rechecks before blocking, supports relative timeout, and returns `EAGAIN`/`ETIMEDOUT`/`EINTR` on the real wait path. `WAKE` validates the futex address and wakes address/key-matched waiters. `WAIT_BITSET`/`WAKE_BITSET` share the same wait path with bitset filtering and absolute timeout handling. `FUTEX_PRIVATE_FLAG` uses address-space-private keys; shared futex ops use a cross-process key for the same user address. Futex waiters and their timeout tokens are removed when the waiter returns or when the task is killed/exits, so later wakes/timeouts do not depend on stale pop-time filtering. `set_robust_list` validates the Linux head size and records the per-task robust head; `get_robust_list` returns the recorded head/length for the current task or a known pid. On thread exit, non-PI robust entries owned by the exiting TID are marked `OWNER_DIED` and both private/shared waiters are woken; `clear_child_tid` wakes through the exiting task's private futex key. Unsupported futex ops return `ENOSYS` instead of fake success. PI, requeue, inode/page-cache-accurate shared keys, realtime futex details, and full pthread cancellation semantics remain `missing`/`partial`. |
| Time/system info: `nanosleep`, `clock_gettime`, `gettimeofday`, `times`, `getrusage`, `uname`, `sysinfo`, `getrandom` | `partial` | `os/src/syscall/other.rs`, `os/src/timer.rs`, `patch/polyhal/src/components/timer/riscv64.rs` | Enough for libc startup and basic utilities. RISC-V timer frequency is aligned with the QEMU/OpenSBI 10 MHz mtimer value. `getrusage(RUSAGE_SELF/RUSAGE_THREAD)` returns a real Linux-layout `rusage` with elapsed user time from task start and zeroed counters; `RUSAGE_CHILDREN` returns a zero structure. Accuracy, CPU/user split, child accounting, and many clock IDs are simplified. |
| Scheduler/rlimit/identity stubs | `stub-ok` to `stub-risk` | `os/src/syscall/other.rs`, `os/src/syscall/mod.rs` | UID/GID are fixed zero. Scheduler calls mostly return success. `getrlimit`, `setrlimit`, and `prlimit64` now maintain per-task `RLIMIT_NOFILE` state, inherit it across `clone`, and apply the soft fd limit to `openat`, `pipe2`, `dup`, `dup3`, `fcntl(F_DUPFD*)`, `socket`, and `accept4`; other resource limits still report infinity or compatibility-success behavior. |
| Networking: socket family | `partial` | `os/src/syscall/net.rs`, `os/src/fs/fd.rs`, `os/src/syscall/fs.rs`, `os/src/syscall/mod.rs` | `socket` creates real fd-table socket descriptors with `SOCK_NONBLOCK`/`SOCK_CLOEXEC`; `bind` validates local sockaddrs, assigns ephemeral ports for port 0, and records bound sockets; `listen` records stream listener state; `connect` to a bound in-kernel listener queues a real accepted socket; `accept/accept4` returns pending stream sockets and reports `EAGAIN` for nonblocking no-pending-connection. Datagram `sendto`/`recvfrom` deliver payloads through bound local receive queues, and stream `read`/`write`/`sendto`/`recvfrom` use peer byte queues after loopback connect. `getsockname/getpeername`, `shutdown`, `getsockopt/setsockopt` for common `SOL_SOCKET` options including `SO_PROTOCOL` plus `TCP_NODELAY`, and socket `ioctl(FIONBIO/FIONREAD)` have compatibility behavior. There is still no virtio-net/external network path, no real TCP congestion/window/close protocol, no UDP routing beyond local bound sockets, no `socketpair`, and limited socket option/ioctl coverage; unsupported protocols/options return `EPROTONOSUPPORT`, `ENOPROTOOPT`, `ECONNREFUSED`, or `EOPNOTSUPP` rather than success. |

## Process Lifecycle Details

| Syscall / area | Status | Current semantics | Remaining risk |
| --- | --- | --- | --- |
| `wait4` child selection | `partial` | `pid == -1` and `pid == 0` wait for any child process in the caller's thread group; positive `pid` matches child TGID. A live child with `WNOHANG` returns `0`; no matching child returns `ECHILD`. Threads created with `CLONE_THREAD` are not waitable children. | `pid < -1` process-group waits are `missing`; stopped/continued states and Linux wait option filtering are not modeled. |
| `exit` / `exit_group` | `partial` | Raw `exit` makes only the current task zombie, clears `clear_child_tid`, wakes futex waiters through the exiting task's futex key, marks owned non-PI robust-list futexes `OWNER_DIED`, and marks the process zombie when all user threads are gone. `exit_group` applies that termination to every user thread in the TGID, removes each terminated task from ready and wait structures, queues child-exit `SIGCHLD` to the parent, and wakes child waiters once. | Signal default actions, PI robust mutexes, `SA_NOCLDWAIT`, stopped/continued child notifications, and complete robust-list edge cases remain incomplete. |
| `clone` flags | `partial` | Accepts `CLONE_VM`, `CLONE_FS`, `CLONE_FILES`, `CLONE_SIGHAND`, `CLONE_THREAD`, `CLONE_SYSVSEM`, `CLONE_SETTLS`, `CLONE_PARENT_SETTID`, `CLONE_CHILD_SETTID`, and `CLONE_CHILD_CLEARTID`. Enforces `CLONE_SIGHAND -> CLONE_VM` and `CLONE_THREAD -> CLONE_SIGHAND`. `getpid()` returns TGID; `gettid()` returns task PID; `getppid()` returns parent TGID. | Unsupported clone bits return `EINVAL`; `CLONE_SYSVSEM` is accepted as compatibility state only. `CLONE_PARENT`, namespaces, signal-group details, TLS arch edge cases, and full pthread/futex semantics remain `missing`/`stub-risk`. |
| `execve` lifecycle | `partial` | Replaces the current address space, resets signal handlers, updates `exec_path`, terminates peer threads in the TGID, closes descriptors marked `FD_CLOEXEC`, and treats `/proc/self/exe`/`/proc/thread-self/exe` as the current executable. | Linux's full exec credential, dumpability, robust futex, and process-group/session side effects are not modeled. |

## Memory Details

| Syscall / area | Status | Current semantics | Remaining risk |
| --- | --- | --- | --- |
| `brk` heap growth/shrink | `real` for the tracked heap range | `brk(0)` returns the current break. Valid growth maps new anonymous heap pages, valid shrink unmaps pages above the new rounded break, and sub-page break movement only updates the logical break. Invalid below-heap, overflow, stack-boundary, overlap, or allocation-failure requests preserve the old break, matching raw Linux `brk` behavior used by libc allocators. | No overcommit policy, guard gap, or per-VMA heap tag; a user can still deliberately replace heap pages with `MAP_FIXED`, as on Linux. |
| Anonymous `mmap` | `real` for private/shared anonymous pages used by libc | Requires one of `MAP_PRIVATE`, `MAP_SHARED`, or `MAP_SHARED_VALIDATE`, validates `prot`, length, fixed-address alignment, user range, and common Linux compatibility flags. Non-fixed hints are page aligned and fall back to a free region. `MAP_FIXED_NOREPLACE` returns `EEXIST` on overlap; fixed address 0 is rejected with `EPERM`. | No lazy fault, overcommit accounting, `MAP_GROWSDOWN`, huge pages, locked memory, or NUMA/accounting semantics. Compatibility flags such as `MAP_STACK`, `MAP_POPULATE`, and `MAP_NORESERVE` are accepted with no special effect. |
| `munmap` | `real` for page-aligned partial VMA removal | Splits VMAs at page boundaries, unmaps the requested range even when it cuts through an area, and coalesces surviving adjacent areas. Writable shared file-backed ranges are written back before removal. | No dirty-page tracking; writeback is range-wide and eager for shared file-backed mappings. |
| `mprotect` | `partial` | Validates alignment/length/prot, requires the full range to be mapped as a VMA, splits VMAs, allocates zero-filled frames for previously reserved `PROT_NONE` ranges when leaf permissions are added, and rewrites page-table permissions. `PROT_WRITE` also grants read permission to avoid invalid RISC-V W-without-R PTEs. | No architecture-specific execute/cache synchronization beyond remapping, and no Linux personality/read-implies-exec behavior. |
| SysV shared memory: `shmget`, `shmat`, `shmdt`, `shmctl` | `partial` | `IPC_PRIVATE` and keyed `shmget` create or find real page-backed segments, `IPC_CREAT|IPC_EXCL` reports `EEXIST`, `shmat` maps the segment into the caller with real shared physical frames, fork clones preserve those shared mappings, `SHM_RDONLY` removes write permission, `shmdt` unmaps the full attachment even after VMA splitting, task exit and `execve` detach live attachments, and `shmctl(IPC_STAT/IPC_RMID)` reports basic metadata or marks/removes segments after the final detach. This is enough for iozone throughput workers and the libc-test `ipc_shm` style lifecycle. | No namespace isolation, `SHM_INFO`/`SHM_STAT`/`IPC_INFO`, permission enforcement beyond basic mode metadata, huge pages, `SHMLBA` nuances beyond page rounding, or complete Linux `shmid_ds` edge cases. Unsupported control commands return errors instead of fake success. |
| File-backed `mmap` | `partial` | Readable regular file descriptors can be copied into private/shared framed VMAs when the mapping has leaf permissions; `PROT_NONE` file-backed reservations record the VMA without pre-reading inaccessible file bytes. Writable `MAP_SHARED|PROT_WRITE` requires a writable descriptor and writes back on `munmap` or fixed replacement. | Not a complete page-cache mapping: no lazy population of file contents after `mprotect`, shared physical page coherence, partial dirty tracking, `msync`, truncate invalidation, or DAX/`MAP_SYNC`; unsupported validated flags report `EOPNOTSUPP`/`EINVAL` instead of pretending success. |

## Signal Details

| Syscall / area | Status | Current semantics | Remaining risk |
| --- | --- | --- | --- |
| `rt_sigaction` ABI and flags | `partial` | Uses the common Linux kernel layout `{ handler, flags, restorer, mask }`. Unsupported/probing bits are cleared from stored actions; `SIGKILL` and `SIGSTOP` cannot be caught or ignored. `SA_RESTORER`, `SA_NODEFER`, and `SA_RESETHAND` affect delivery. `SA_SIGINFO` provides a minimal 128-byte siginfo with signo/code/sender pid. | No full `ucontext_t`, alternate signal stack, or syscall restart. `SA_RESTART`, `SA_ONSTACK`, `SA_NOCLDSTOP`, `SA_NOCLDWAIT`, `SA_INTERRUPT`, and `SA_EXPOSE_TAGBITS` are compatibility-accepted but not fully modeled. |
| `rt_sigprocmask` / pending relation | `partial` | Each task has a real blocked mask and pending bitset; `SIGKILL`/`SIGSTOP` are removed from user masks. Unblocking exposes pending signals, and deliverable pending signals interrupt wait-queue sleeps with `EINTR`. | Process-wide shared pending queues and realtime queued-signal multiplicity are missing. |
| `rt_sigreturn` | `partial` | Restores the saved arch trap frame and previous blocked mask from the user signal frame, then returns to the interrupted PC without advancing the syscall PC. | The frame is kernel-private, not a complete Linux `ucontext_t` ABI. Corrupt frames fail with `EINVAL`. |
| `kill` / `tkill` / `tgkill` targets | `partial` | Positive `kill(pid, sig)` targets the TGID and prefers a live thread that is not blocking the signal; `tkill` targets a TID; `tgkill` verifies TID membership in TGID. Signal 0 validates targets without delivery. `kill(-1, sig)` targets all user tasks. | Process groups (`pid == 0` as caller process group and `pid < -1`) are not real; the BusyBox-compatible "seen TGID" success path remains for exited positive TGIDs. |
| `sigsuspend` / `sigtimedwait` | `partial` | `rt_sigsuspend` reads the temporary mask, sleeps on the signal wait queue, returns `EINTR` on delivery, and restores the caller's old mask through `rt_sigreturn`. `rt_sigtimedwait` reads the user signal set, consumes matching pending signals, writes minimal siginfo, waits with a timeout, and returns `EAGAIN` on timeout. | Shared process-pending queues, realtime queued-signal multiplicity, restart behavior, and full `siginfo_t`/`ucontext_t` details remain incomplete. |

## High-Priority Gaps

1. Harden FD/VFS contract before more suites: `os/src/fs/vfs.rs`, `os/src/fs/fd.rs`, `os/src/syscall/fs.rs`.
   Broaden descriptor-shared status flags beyond the current pipe `O_NONBLOCK` and regular `O_APPEND` subset, then finish full rename/link/symlink semantics and clearer metadata/open tests around MemFS overlay plus ext4.

2. Make blocking semantics observable and less foreground-specific: `os/src/task/wait_queue.rs`, `os/src/task/mod.rs`, `os/src/syscall/process.rs`, `os/src/syscall/other.rs`.
   The current lifecycle path now purges ready, futex, timer, IO, child-exit, and signal wait entries on task exit/kill. Next, extend `BlockReason` into debug logs and replace remaining direct blocking entry points as new waits appear.

3. Finish pthread/libc basics: `os/src/syscall/process.rs`, `os/src/syscall/other.rs`, `os/src/syscall/signal.rs`.
   Prioritize pthread cancellation/exit status, robust futex owner-death cleanup, `clone` thread semantics, shared futex keys, and `rt_sigsuspend`.

4. File and pipe workload support for `iozone`, `lmbench`, and UnixBench: `os/src/fs/fd.rs`, `os/src/syscall/fs.rs`, `os/src/fs/ext4_vol.rs`, `os/src/mm/memory_set.rs`, `os/src/syscall/mm.rs`.
   Continue from the real iozone boundary by improving fixed-offset/vector write throughput after the now judge-visible pwritev/preadv phase. For lmbench, the next frontier is real pipe latency/bandwidth progress after `pselect6` and `SIGPIPE`, followed by dirty tracking/`msync`, descriptor-shared file offsets, sparse-hole accounting, and less stubby persistence for `fsync`/`fdatasync`.

5. Network suites last: extend the new `os/src/syscall/net.rs` socket fd layer from local in-kernel loopback queues to a real TCP/IP or minimal virtio-net-backed packet path.
   The fd lifecycle, option compatibility, nonblocking errno, local connect/accept, local payload queues, and poll/select hooks exist; the next step is a real network stack boundary with protocol semantics.

## Suggested Enable Order

1. Keep `basic`, `busybox`, `lua`, and tail-position `libc-test` as the default harness groups so judge-visible libc-test markers are emitted after the established regressions; default libc-test now uses the musl staged collector for the scored path.
2. Use the `libctest` feature for explicit full/staged collection runs; it still preserves segment logs for glibc/musl static/dynamic/extra evidence inside official `libctest-glibc` / `libctest-musl` groups and has an opt-in compile-time `LIBCTEST_FILTER` to shorten local validation without changing the default scored path.
3. Keep the already-passing `basic`/`busybox`/`lua` groups under dual-architecture regression while preserving libc-test evidence from real serial logs.
4. Grow beyond libc-test by real failing categories next: keep the score-complete libc-test path green, run lmbench after iozone on the `IOZONE=1` path, keep libcbench after libc-test, then move to UnixBench/LTP pressure without relabeling unsupported behavior as passes.
5. On the `feat/iozone` branch, keep Makefile builds pointed at the full baseline plus iozone/lmbench/libcbench harness; use `IOZONE=0` when refreshing the narrower baseline without iozone/lmbench/libcbench.
6. Keep `LMBENCH=1` available as a focused lmbench-only bring-up mode, then enable `UnixBench` after scheduler, pipe, wait, and timing behavior are less synthetic.
7. Enable `LTP` only after the matrix is split by LTP subsystem.
8. Enable `iperf/netperf` only after the socket layer has a real network data path and protocol semantics, not just local fd/loopback queue support.
