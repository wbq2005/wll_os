```
entry.asm → rust_main() → mm::init_heap() → logging::init() 
→ polyhal::common::init() → 遍历内存区域 → fs::init() 
→ fs::list_apps() → task::init_kernel_page() → task::add_initproc() 
→ task::run_tasks()
```

## 二、增量开发策略

### 2.1 核心思路
**不是从零写，而是基于Nonix做改进：**
1. 复制Nonix的核心框架（已验证可工作）
2. 保留其系统调用、文件系统、内存管理等成熟实现
3. 在以下方面做增量创新：
   - 调度算法优化（CFS → 混合调度）
   - 内存分配优化（Buddy → 自适应分配）
   - 文件系统缓存优化
   - 驱动框架改进
   - 性能调优

### 2.2 与Nonix的差异点（创新点）
| 模块 | Nonix实现 | 12345改进 |
|------|----------|----------|
| 调度器 | 基础优先级调度 | CFS + EDF混合调度 |
| 内存分配 | 标准Buddy | 自适应分配器 |
| FS缓存 | 基础缓存 | 智能预读+写回 |
| 驱动 | 直接实现 | 统一驱动框架 |
| 同步 | 自旋锁 | 睡眠锁优化 |
